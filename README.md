# Student Performance Analytics

## 📌 Project Overview

Student Performance Analytics is a Python-based data analysis project that analyzes students' academic performance using data analysis and visualization techniques.

The project uses **Pandas** and **NumPy** for data processing and numerical analysis, while **Matplotlib** and **Seaborn** are used to create meaningful visualizations.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Dataset

The dataset contains student information such as:

* Student ID
* Name
* Department
* Age
* Gender
* Attendance
* Study Hours
* Assignments
* Math Marks
* Python Marks
* English Marks
* Previous GPA

## 🔍 Analysis Performed

The project performs:

* Dataset inspection
* Missing value analysis
* Duplicate detection
* Department analysis
* Average marks calculation
* Total marks calculation
* Student-wise performance analysis
* Subject-wise performance analysis
* Academic risk identification
* Attendance analysis
* Study hours analysis
* Correlation analysis
* Student ranking
* Weakest subject identification
* Top-performing student identification

## 📈 Data Visualizations

The project includes the following visualizations:

1. Average Marks by Department
2. Study Hours vs Average Marks
3. Subject-wise Average Marks
4. Attendance vs Average Marks
5. Student Performance Distribution
6. Correlation Heatmap

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/fh545599-byte/Student_Performance_Analytics.git
```

### 2. Open the project folder

```bash
cd Student_Performance_Analytics
```

### 3. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### 4. Run the project

```bash
python main.py
```
